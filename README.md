# stm32_load_pwm

Компактная C-библиотека для управления яркостью/мощностью произвольной ШИМ-нагрузки на **STM32**: светодиоды (циклы индикации, гамма-коррекция под нелинейное восприятие) и линейная нагрузка — лампы накаливания, кулеры охлаждения, DC-моторы, электромагниты (без гамма-коррекции). Неблокирующая, без malloc, не привязана к конкретному аппаратному "главному" таймеру.

## Зачем нужна

Часто нужно управлять яркостью/мощностью нагрузки не тупым вкл/выкл, а плавно или по красивому циклу — но реализовывать таймеры, фазовые аккумуляторы и гамма-коррекцию под каждый проект заново — рутина. Библиотека берёт это на себя: каждая нагрузка на своём канале ШИМ, периодическое обновление — одним вызовом `LOAD_PWM_Tick()` откуда угодно (таймер, main-loop, RTOS), а форма цикла — из готовой таблицы.

## Поддерживаемые платформы

- **STM32F4**, **STM32H7** и, в целом, любой STM32 с периферией TIM и HAL — используется только стандартный HAL TIM.

## Основной функционал

- Регистрация произвольного числа нагрузок (лимит настраивается, по умолчанию 16) через `LOAD_PWM_Init()`, каждая — со своим типом (`LOAD_PWM_TYPE_LED` / `LOAD_PWM_TYPE_LINEAR`).
- **Гамма-коррекция для светодиодов**, откалиброванная под ваше железо: три опорных уровня скважности ШИМ (0%, ~50%, 100% визуальной яркости). Не хотите измерять точку 50% — задайте отрицательное значение, и библиотека применит типовую gamma (2.2) вместо калибровки по факту.
- **Линейный режим для прочей нагрузки** (лампы, кулеры, моторы, электромагниты) — скважность ШИМ пропорциональна заданному значению напрямую, без гамма-коррекции.
- 8 готовых циклов индикации на константных таблицах: меандр, "дыхание", импульс с ожиданием, полутрапеция, полупила, треугольник, двойной проблеск, строб.
- Зацикленный запуск, однократный запуск и остановка цикла — с настраиваемым сдвигом по фазе.
- Фоновая яркость с опциональным плавным переходом между значениями фона.
- **`LOAD_PWM_StopAll()`** — аварийный сброс всех нагрузок разом.
- **`LOAD_PWM_SetGlobalBrightness()`** — глобальный "ночной" множитель для всех нагрузок сразу, накладывается после гамма-коррекции.
- **Не привязана к главному таймеру**: обновление — вызовом `LOAD_PWM_Tick(tick_source_id)` из прерывания, main-loop или RTOS-задачи, с любой периодичностью, примерно соответствующей заявленной частоте.
- Полностью неблокирующий и быстрый API: в `Tick()` — только сложение, сравнение, сдвиг, табличная выборка и одна линейная интерполяция на нагрузку.

## Как использовать

```c
#include "stm32_load_pwm.h"

LOAD_PWM_Handle_t *status_led;
LOAD_PWM_Handle_t *cooling_fan;

void LoadsInit(void)
{
    /* Светодиод - с типовой гаммой (точку 50% не измеряли) */
    LOAD_PWM_Config_t led_cfg = {
        .tick_source_id = 0,       /* группа "тикающая" из таймера htim6 */
        .tick_freq_hz   = 1000,    /* 1000 Гц - реальная частота ваших вызовов LOAD_PWM_Tick(0) */
        .htim           = &htim3,
        .channel        = TIM_CHANNEL_1,
        .load_type      = LOAD_PWM_TYPE_LED,
        .brightness_min_percent = 0.0f,
        .brightness_mid_percent = -1.0f,   /* не измеряли - типовая gamma 2.2 */
        .brightness_max_percent = 100.0f,
    };
    status_led = LOAD_PWM_Init(&led_cfg);

    /* Кулер охлаждения - линейная нагрузка, та же группа тика */
    LOAD_PWM_Config_t fan_cfg = {
        .tick_source_id = 0,
        .tick_freq_hz   = 1000,
        .htim           = &htim4,
        .channel        = TIM_CHANNEL_1,
        .load_type      = LOAD_PWM_TYPE_LINEAR,
        .brightness_min_percent = 0.0f,
        .brightness_mid_percent = -1.0f,   /* игнорируется для LINEAR */
        .brightness_max_percent = 100.0f,
    };
    cooling_fan = LOAD_PWM_Init(&fan_cfg);
}

void OnDeviceOk(void)
{
    LOAD_PWM_Start(status_led, LOAD_PWM_CYCLE_BREATH, 0.0f, 2000);
    LOAD_PWM_SetBrightness(cooling_fan, 40.0f, 0); /* кулер на 40% мощности */
}
```

```c
/* Периодическое обновление - здесь из прерывания таймера, но с тем же
   успехом можно вызывать из while(1) в main() или из задачи RTOS */
void HAL_TIM_PeriodElapsedCallback(TIM_HandleTypeDef *htim)
{
    if (htim == &htim6)
    {
        LOAD_PWM_Tick(0); /* группа tick_source_id = 0, см. LoadsInit() выше */
    }
}
```

## Требования к настройке в CubeMX

- **Таймер(ы) нагрузок**: соответствующий канал в режиме PWM Generation, частота ШИМ — без видимого мерцания/жужжания (обычно от 1 кГц), ARR — по вкусу. Отдельного "главного" таймера настраивать не нужно.
- Явно вызывать `HAL_TIM_PWM_Start` не нужно — библиотека делает это сама при регистрации. Периодичность вызова `LOAD_PWM_Tick()` обеспечиваете вы сами — любым удобным способом.

## Честные ограничения

- Гамма-кривая для LED — единая степенная функция `x^gamma`, откалиброванная по одной измеренной точке (или типовому значению) — разумное приближение, а не физически измеренная кривая всего диапазона.
- Набор циклов фиксирован восемью формами — своя произвольная форма потребует добавить таблицу в `stm32_load_pwm.c`.
- Плавный переход (`fade_ms`) работает только между фоновыми значениями, когда простаивает — переходы цикл↔фон всегда мгновенные.
- `LOAD_PWM_Tick()` не отслеживает реальное прошедшее время — точность цикла зависит от того, насколько стабильно вы вызываете её с заявленной `tick_freq_hz`. Для точных таймингов используйте аппаратный таймер, для приблизительных — main-loop подойдёт.
- Групповые "бегущие" эффекты, RGB-обёртка, калибровка "на лету" и хранение калибровки в энергонезависимой памяти — сознательно не реализованы (см. `Список_идей.md`).
